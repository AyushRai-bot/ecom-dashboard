# E-Commerce Database Dashboard

A Flask web app to manage and visualize an e-commerce MySQL database.

## Features
- Customer management & order history
- Sales reports & analytics
- Product discounts & price history
- Payment method analysis

## Setup
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Set up MySQL database and configure `.env`
4. Run: `python app.py`
